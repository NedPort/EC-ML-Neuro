# EC-Transformer

A transformer-based framework for fNIRS analysis integrating temporal dynamics and effective connectivity (EC) representations for cognitive-state decoding and neuroimaging analysis.

The project combines:
- Time-wise embeddings from HbO/HbR signals
- Effective connectivity-based representations
- Transformer encoders
- Adaptive gating mechanisms for multimodal fusion

The framework is designed to model both temporal and connectivity-related information from fNIRS recordings while preserving interpretability of cortical interactions.

## Features

- Effective connectivity modeling using MVAR-based methods
- Connectivity-informed transformer architecture
- Adaptive gating fusion between multiple physiological representations
- Lightweight transformer design for efficient training
- Graph-based and temporal representation learning

## Applications

- Cognitive-state decoding
- Brain-computer interfaces (BCI)
- Neuroimaging analysis
- fNIRS-based classification tasks
- Connectivity-aware representation learning
